## TDD
this projects follows TDD approach
you can run tests with `pnpm test`

We especially give value to end to end tests. New features should be implemented after 
end to end tests are implemented. End to end test should not look into implementation details. It should look for the behaviour for users.

Other tests should be implemented after the implementation of code.
In brief when we develop a new feature we should follow: 
end to end test -> implementation -> unit tests
